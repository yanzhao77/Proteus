This matrix is a contract for P3-1 and later implementation. P3-0 is a
documentation-only slice: runtime rows are `PLANNED`, not `PASS`.

`SPECIFIED`, `PLANNED`, `PARTIAL`, `PASS`, `BLOCKED`.
